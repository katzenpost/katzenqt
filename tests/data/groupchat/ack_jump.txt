# The fix for flaw (b): a scan jumps to the furthest box any member has
# acked on the stream. The messages in the hole are lost, but the stream is
# readable again.

option ack-jump on
new-group alice bob carol
send alice m0
send alice m1
read carol alice        # carol keeps up
tick 6
send alice m2
read carol alice
send carol c0
read bob carol
scan bob alice
----
alice@0 recheck: not found
alice@1 recheck: not found
alice@2 "m2"
alice@3 not found

send alice m3
read bob alice
----
alice@3 "m3"
alice@4 not found
