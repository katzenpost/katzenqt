# Flaw (b): a scan cannot cross a hole. Bob stays away longer than alice's
# Sent-box window plus the box lifetime, so alice's first boxes are gone.
# Newer boxes exist, and carol has acked one, yet scanning stops at the
# first BoxIDNotFound. Carol's ack is evidence that bob is stuck, and it
# names a box bob could read from.

new-group alice bob carol
send alice m0
send alice m1
read carol alice        # carol keeps up
tick 6
send alice m2
read carol alice
send carol c0            # acks alice@2
----
carol@0 "c0" acks 1:alice@2

read bob carol
----
carol@0 "c0" acks 1:alice@2
carol@1 not found

read bob alice
----
alice@0 not found
  stuck: carol acked alice@2

scan bob alice
----
alice@0 not found
