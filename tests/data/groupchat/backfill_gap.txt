# A box lives through the epoch it was written in and the next, and a
# rewrite in that time changes nothing. From the start of the epoch after,
# it is gone until its owner's backfill writes it again.

new-group alice bob carol
send alice hello
epoch
backfill alice
backfill alice           # at most once per epoch
epoch
peek alice 0

read bob alice

backfill alice
read bob alice
