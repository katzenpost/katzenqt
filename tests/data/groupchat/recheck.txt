# The backward recheck. Carol's boxes are missing for a while because she
# has not yet backfilled this epoch. Bob jumps past them on alice's ack,
# keeping the indexes he skipped, and so misses the Introduction of erin.
# Once carol backfills, a second scan fetches the skipped boxes and bob
# learns who alice's index 3 is. Bob acknowledges none of carol's boxes
# until he has read every one of them.

new-group alice bob carol
send carol c0
introduce carol erin
read alice carol
send alice a0            # numbers erin, then acks carol
epoch 2                  # carol's first boxes expire
backfill alice           # carol has not backfilled yet
send carol c2
read alice carol
send alice a1            # acks carol@2
read bob alice
read bob carol           # stuck
----
carol@0 not found
  stuck: alice acked carol@2

scan bob carol           # jumps
----
carol@2 "c2"
carol@3 not found

roster bob alice
----
carol alice bob ?

send bob b0              # carol@0 and carol@1 unread: no ack of carol
read carol bob
acked carol
----
none

scan bob carol           # carol has not backfilled: still missing
----
carol@0 recheck: not found
carol@1 recheck: not found
carol@3 not found

backfill carol
scan bob carol
----
carol@0 "c0"
carol@1 introduces erin numbers 3:erin
carol@3 not found

roster bob alice
----
carol alice bob erin

send bob b1              # every box read: acks carol@2
read carol bob
acked carol
----
bob:carol@2
