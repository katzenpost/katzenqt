# The proposed fix for flaw (a): backfill writes a purged message as a
# message keeping only its Acks and Introduction, instead of an empty
# tombstone. A replica refuses a write that differs from a box it still
# keeps, so the redacted message can only replace the original once the
# original has expired; until then the plaintext stays readable.

option redact on
new-group alice bob carol
introduce carol dave
read alice carol
read bob carol
send alice hi            # numbers dave
purge alice
tick
----
  alice@0 write refused

read bob alice
----
alice@0 "hi" acks 0:carol@0
alice@1 not found

tick
----

read carol alice
----
alice@0 acks 0:carol@0
alice@1 not found

send dave hello
read alice dave
send alice again         # acks dave
read carol dave
read carol alice
roster carol alice
----
carol alice bob dave

acks carol alice 1
----
dave@0
